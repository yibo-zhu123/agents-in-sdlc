通过真实场景、完整应用程序和共享待办事项，在软件开发生命周期中探索 GitHub Copilot。您将通过迭代来规划更改、编写代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

您是 Tailspin Toys 的新开发人员。这是一家虚构公司，为棋盘游戏众筹，且以开发者为主题。团队的待办事项已整理为 GitHub 议题，供您认领，其中包括筛选和分页等功能开发，以及无障碍访问和编码规范等质量改进。

## 选择工作环境

GitHub Copilot 可以融入您选择的工作环境。选择适合您的开发方式的环境。每个研讨会都有自己的设置步骤，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体助手。探索 Plan 和 Autopilot 模式、指令、技能、自定义智能体、Playwright MCP、Agent Merge 和实用的斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行智能体会话、切换会话模式、协作使用 Canvas，并管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub 议题分配给异步智能体、引导其工作、监视进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
